Gimmick sandbox

← back to the room my settings theme gallery

Write a gimmick (a little JavaScript that runs in your browser) and try it against a sample room on the right. Nothing is saved or sent until you press “Save as my custom JS”. If something breaks, the room has a safe mode: /room?safe=1.

What can I use? 
Room.me                      { id, name, color, admin }
Room.on(event, fn)           'message' 'incoming' 'mention' 'sent' 'send-error' 'queued'
                             'conn' 'users' 'count' 'room' 'ready'
Room.card('Title')           adds a card to the side panel (returns the element)
Room.banner(element)         puts an element above the top bar
Room.background              full-screen decorative layer
Room.setTimeFormatter(fn)    fn(message, Date) -> string, or null for the default
Room.users() / Room.rooms()  who and where
Room.currentRoom()           id of the channel being viewed
Room.gimmick({id, init})     register a gimmick like the built-in ones

Message: { id, uid, name, text, ts, room, mentions, fx, reactions, reply, image }
CSS hooks: .msg  .mine  .system  .mention-me  .quote  .reactions  .react  .mention  [data-sender]

The preview uses your saved theme. The fake messages come from “Mina”.
